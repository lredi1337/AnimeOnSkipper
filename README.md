# 🎬 AnimeOn Skipper

Расширение для браузера и облачная база данных для автоматического и удобного пропуска опенингов и эндингов на **[AnimeOn](https://animeon.cc/)** и в плеерах **Kodik**.

---

## 🌟 Возможности

* **Автоматический пропуск**: Мгновенный переход через опенинги и эндинги по меткам из общей базы данных.
* **Встроенный редактор меток прямо в плеере (`Alt + M`)**:
  * Удобная разметка начала и конца заставок прямо во время просмотра.
  * Мгновенный предпросмотр интервалов на шкале времени плеера.
  * Отправка меток в облачную базу в один клик.
* **Синхронизация с настройками сайта**: поддержка нативных переключателей автопропуска в интерфейсе плеера.
* **Работа в полноэкранном режиме**: редактор и кнопки доступны как в обычном окне, так и на весь экран.
* **Облачная база меток (Cloudflare Worker)**:
  * Единая база таймкодов для всех серий и сезонов.
  * Система консенсуса и модерации для защиты от неверных меток.
  * Личный кабинет и сайт для просмотра разметки и управления тайтлами.

## 🚀 Установка расширения

Расширение работает во всех браузерах на базе Chromium (**Google Chrome, Яндекс Браузер, Microsoft Edge, Brave, Opera**).

### Инструкция:

1. **Скачайте расширение:**
   * Нажмите зелёную кнопку **Code** вверху страницы репозитория ➔ выберите **Download ZIP**.
   * Распакуйте скачанный архив в любое удобное место (например, в отдельную папку или Документы). *Не удаляйте эту папку после установки.*

2. **Откройте менеджер расширений в браузере:**
   * Введите в адресную строку браузера:
     * **Chrome / Brave:** `chrome://extensions`
     * **Яндекс Браузер:** `browser://extensions`
     * **Edge:** `edge://extensions`
     * **Opera:** `opera://extensions`

3. **Включите режим разработчика:**
   * В правом верхнем углу страницы переведите тумблер **«Режим разработчика»** (Developer mode) в активное положение.

4. **Загрузите расширение:**
   * В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
   * В открывшемся окне выберите папку **`extension`** из распакованного архива.

5. **Готово!**
   * Расширение установлено и активировано.
   * Для удобства нажмите на значок «пазла» 🧩 на панели браузера и закрепите **AnimeOn Skipper**.
   * Откройте любую серию на **animeon.cc** — пропуск и разметка уже работают!
