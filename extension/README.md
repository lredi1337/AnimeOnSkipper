# AnimeOn Skipper — Расширение для пропуска опенингов и эндингов

Удобное расширение для онлайн-кинотеатра **[AnimeOn](https://animeon.cc/)** и плееров Kodik, которое автоматически пропускает опенинги и эндинги, используя нативные метки сайта и синхронизированную облачную базу Cloudflare.

---

## ⚡ Как это работает

Расширение работает по строгой двухуровневой системе приоритетов:

1. ****:  
   Если нативных меток нет, расширение обращается к собственной базе Cloudflare Workers + KV.
   - Когда тайминги загружены из нашей базы, они отображаются на шкале таймлайна в едином стиле и синхронизируются с нативными настройками автопропуска на сайте.
   - Вы также можете в 1 клик зафиксировать таймкод опенинга через мини-панель `[ ⏩ +89с ]`, `[ [ Начало ]` и `[ Конец ] ]` — они сразу сохраняются и отправляются в базу.

---

## ⏩ Механика перемотки

* **Пролог не затрагивается**: До наступления `interval.start` плеер воспроизводит видео в обычном режиме без вмешательства.
* **Точный вход**: Пропуск срабатывает строго при естественном входе в интервал `[start, end)`.
* **Сцены после титров сохранены**: Для эндинга точка перехода всегда строго `end`, гарантируя просмотр сцен после титров.

## 🚀 Установка в браузер (Chrome / Edge / Яндекс Браузер / Opera)

1. Откройте страницу расширений в вашем браузере:
   - В **Google Chrome**: перейдите по адресу `chrome://extensions/`
   - В **Microsoft Edge**: перейдите по адресу `edge://extensions/`
   - В **Яндекс Браузере**: `browser://extensions/`
2. В правом верхнем углу включите переключатель **«Режим разработчика»** (*Developer mode*).
3. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
4. Выберите папку:
   ```
   c:\Users\PC\Desktop\animeon1\extension
   ```
5. Расширение установлено и готово к работе!

## 🎮 Возможности и управление

* **Кнопка «Пропустить опенинг / эндинг»**: появляется в плеере на время заставки (в обычном и полноэкранном режиме).
* **Синхронизация автопропуска**: управляется нативными тумблерами прямо в шестеренке плеера на AnimeOn или во всплывающем меню расширения.
* **Маркеры на прогресс-баре**: оранжевая зона для опенинга, бирюзовая зона для эндинга с тултипом точного времени.
* **Смещение тайминга (Offset)**: в меню расширения можно задать коррекцию от -5 до +5 секунд для специфических заставок озвучки.
* **Горячие клавиши**:
  - `S` (или русская `Ы`) — мгновенно перейти на конец текущей заставки (`end`) или промотать 89 секунд.
